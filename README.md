# 🍴 Abhis Kitchen Website

Welcome to **Abhis Kitchen** — a simple and attractive restaurant website created using **HTML and CSS**.

The website provides information about the restaurant, food menu, special offers, table reservations, gallery, and contact details.

## 🌐 Website Pages

* 🏠 **Home** – Introduction to Food Corner
* ℹ️ **About Us** – Restaurant story, mission, vision, promises, and more
* 🍕 **Our Menu** – Food items, drinks, prices, and photos
* 🪑 **Table Reservation** – Reservation form for customers
* 🖼️ **Gallery** – Food and restaurant images
* 🎉 **Offers** – Special food offers and discounts
* 📞 **Contact Us** – Contact information, message form, and opening hours

## 🛠️ Technologies Used

* HTML5
* CSS3
* Tables
* Forms
* Images
* Hyperlinks
* Basic CSS styling
* Hover effects

The main objective of this project is to practice **HTML and CSS** by creating a multi-page restaurant website.

This project helped me improve my understanding of:

* HTML page structure
* Tables
* Forms
* Links and navigation
* Images
* CSS selectors
* CSS box model
* Borders and shadows
* Hover effects
* External CSS files

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation bar to explore the different pages.
